連結你的 Gemini API 金鑰，以啟用 AI 功能
尚未申請金鑰嗎？可前往 Google AI Studio 免費取得。金鑰只存在這個瀏覽器的 localStorage，並直接由你的瀏覽器呼叫 Gemini，不會經過任何第三方伺服器。
把網站掛上網域後（例如 Cloudflare Pages），請到 Google Cloud Console 幫這把金鑰加上 HTTP referrer 限制， 只允許你自己的網址呼叫。用 file:// 直接開檔案反而沒辦法設這道限制。
Google 換版本很勤，寫死的清單很快就會失效（gemini-2.0-flash 已於 2026 年 3 月退役）。 貼上金鑰後按「載入可用模型」，會直接跟 API 要一份這把金鑰真正能用的清單。 模型沒有免費額度時，Google 回的是 429，不是「找不到模型」，所以第一次呼叫就說到上限，多半是選錯模型而不是真的用完。
備份與還原
所有資料只存在這個瀏覽器裡。清除瀏覽資料、換裝置、或 iOS Safari 連續七天沒開啟，都會讓資料消失。 養成每週匯出一次的習慣，檔案存到雲端硬碟就不怕。
